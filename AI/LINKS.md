# Links

## Official Polar Resources

- Polar AccessLink API v3: https://www.polar.com/accesslink-api/
- Polar AccessLink API v3 OpenAPI specification: https://www.polar.com/accesslink-api/swagger.yaml
- Polar AccessLink Dynamic API v4: https://www.polar.com/polar-api-v4/
- Polar AccessLink Dynamic API v4 Swagger specification: https://www.polar.com/polar-api-v4/swagger.yaml
- Polar AccessLink client administration: https://admin.polaraccesslink.com
- Polar account consents: https://account.polar.com
- Polar AccessLink v3 base URL: https://www.polaraccesslink.com/
- Polar AccessLink v4 data base URL currently referenced by project notes: https://www.polaraccesslink.com/v4/data
- Polar AccessLink v3 authorization endpoint: https://flow.polar.com/oauth2/authorization
- Polar AccessLink v3 token endpoint: https://polarremote.com/v2/oauth2/token

The v3 OAuth endpoints and `accesslink.read_all` scope are verified in `POLAR_API.md`; `POLAR_AUTH_SETUP.md` records the application-specific safe setup procedure. Unmodified local API-specification snapshots, including provenance and checksums, live in `reference/polar-api/`. v4 data endpoint details remain to be verified before use.
